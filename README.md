# ToDoList_Project

A mobile ToDo application built with **Flutter** for the front-end and **Node.js**, **TypeScript**, and **MongoDB** for the back-end.  
The app allows users to manage tasks organized into categories like **Work**, **School**, and **Personal**. Users can perform CRUD operations on categories, lists, and tasks.

## Features

- User **login** with full authentication and validation
- **Gmail service** integration for sending emails
- **JWT** (JSON Web Token) for secure authentication
- **CRUD operations** for categories, lists, and tasks
- Uses **ORM & ODM** for database management
- Backend deployed on **Render**

## Technologies Used

- **Frontend:** Flutter
- **Backend:** Node.js, TypeScript
- **Database:** MongoDB
- **Authentication:** JWT, email validation
- **Deployment:** Render
